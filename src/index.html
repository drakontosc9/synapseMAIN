Dropping a folder
The directory tree is the map. Every folder becomes a bubble, every file becomes a note inside it, and nesting is preserved all the way to the leaves — so a project folder arrives already organised the way you organised it.
lab2a/ empire/ characters/ vader · emperor · bobafett vehicles/ atat · at-st planets/ hoth · endor rebellion/ characters/ luke · leia droids/ r2 · c3p0
You are shown the count, the size and what will be skipped before anything is written. Empty folders are kept, because they are still part of the shape. Build and system folders (node_modules, .git, dist, venv…) and hidden files are left out.
  • Up to 2000 files, 12 levels deep, 256 MB per import.
  • Optionally break every text file into its parts at the same time — that multiplies the note count, so it is off by default.
  • Importing the same folder twice creates a second copy rather than merging.
Dropping a single file
How it decides what matters
1
Headings first. If the document has any # / ## headings, it splits there — one note per section, titled by the heading.
2
Otherwise, lists. Bullet (- * •) and numbered items become one note each, tagged #point.
3
And action lines, anywhere in the file — lines containing todo, action, next step, decision, decided, must, should, deadline, due, owner, risk, blocker, question, follow-up. Tagged #action.
4
Failing all that, the densest sentences in the prose, tagged #highlight. This only runs when nothing structured was found, so bullets are never repeated back at you.
Every part becomes a child note of one document note, so the file arrives as a small map you can zoom into — not a wall of text.
What it can read
Read and split
  • .md .markdown
  • .txt .log
  • .csv .tsv
  • .json
Filed whole, not read
  • .pdf .doc .docx
  • .xls .xlsx .ppt .pptx
  • images, audio, video, .zip
Binary formats are copied into attachments/ and embedded in a note that says so. Synapse does not extract text from PDFs or Word files — there is no parser for them and no AI involved. To break one down, export it to text first.
Limits
  • 64 MB per file — anything larger is skipped and reported.
  • 40 parts per document; the rest of the file is left in the document note.
  • List items shorter than 4 characters are ignored as noise.
  • Highlight sentences must be 30–400 characters.
  • Identical parts are de-duplicated.
  • Frontmatter is stripped, never treated as content.
  • Folders are not accepted — drop the files themselves.
What it will not do
  • It does not summarise or rewrite. Every part is verbatim from your file.
  • It does not judge importance beyond the structural rules above — a bullet is kept because it is a bullet, not because it is wise.
  • It does not merge or de-duplicate against notes you already have.
  • It does not delete or alter the source file; the original is only ever copied.
  • Nothing leaves your machine — there is no network call in any of this.
Getting better results
  • Add headings before importing a long document — that path gives the cleanest split.
  • Meeting notes work best as bullets, one thought per line.
  • Rename the file to something meaningful: the filename becomes the document note's title.
  • Nothing useful came out? Delete the document note — the children go with it — fix the structure, and drop it again.

• Double-click a note to focus just its neighborhood.
• Shift-click notes to select, then group them.
• Ctrl/⌘-K for the command palette · minimap bottom-right to jump around.
